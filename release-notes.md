Benighter Arcade 1.0.2

• Original store layout, console tabs, search and library retained.
• Benighter name, generated app icon and developer signing identity.
• Local player data and saves; original accounts and leaderboards removed.
• Games open in landscape, with manual orientation controls.
• Advertising removed, including save/load interruptions.
• App update checks, verified downloads and normal Android installation approval.

The original catalog contains 1,103 game entries across eight systems. Games are not preinstalled; download availability depends on the original sources. No game files are included in this installer.

NES gameplay, controls and save/load were tested. The N64 test fixture has blank video on the PC emulator and an unresolved native save-state restore problem; N64 operation has not been fully verified. Existing Retro64 data cannot currently be transferred automatically, so keep the old app until your games/saves are safely moved.
